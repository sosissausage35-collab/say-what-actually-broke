A program that writes one line of software error copy — the brutal truth about a server outage — to `/output/entry.txt`, for make.fun's "Say What Actually Broke" bounty.

## Run it

```sh
node main.ts
```

## The line

> The server is down because someone unplugged it to charge their phone. Wait five minutes — the phone should be at 12% by then.

Requires Node.js 22+. The program is deterministic: it always writes the same line (126 characters, one line, UTF-8).
